## 核心理念：六大顶层公理

> 单人超脱存在天花板，上限被所在宇宙存量资源锁死。
> 锚点共生文明，把修炼的选择权还给所有生灵，不断刷新宇宙天花板，持续开发增量，文明光辉播撒多元宇宙。

六大顶层公理是本仓库全部设定的最高法理底座，任何文档与扩容均不得与之冲突：

1. **反掠夺主义公理**：开发增量，不消耗存量；不以杀伐掠夺为进化路径；大道全层级公开，无私藏、无垄断。
2. **万族共和公理**：一切生灵拥有平等进化资格；万族99%全覆盖，打破强者对知识与大道的垄断。
3. **集体升维公理**：强者不独自飞升，抬着万族一起向前进化；万族共和共建、阿赖耶全网共享；杜绝大材小用。
4. **因果自律公理**：跨位面操作严格报备，先观测后有限干涉，只回传知识不扰动因果；彻底根除文明倒退、历史倒车、轮回收割、阶层固化。
5. **法则优先公理**：法则先行，永不吃书、永不烂尾；设定自洽高于剧情便利，剧情不得绑架设定；世界观可无限扩容而不崩坏。
6. **众生全员无限均等法则**：锚点共生文明内，所有生灵自带基础无限之力；佛系/懒狗保有保底基础无限，不会被时代淘汰；卷王、少年至尊可叠加更多更高层级的无限。
